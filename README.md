# HR_Analytics-Dashboard
HR Analytics Dashboard

Project Overview

This project analyzes employee workforce and attrition trends using Power BI. The dashboard provides insights into employee demographics, attrition patterns, overtime impact, business travel, and job roles.

Tools Used

- Power BI
- Excel / CSV
- Data Cleaning
- DAX Measures

Dashboard Pages

Page 1: HR Workforce Overview

- Total Employees
- Attrition Count
- Average Age
- Average Income
- Employee Distribution Analysis

Key Findings

- Attrition rate is 16.09%.
- Overtime employees show higher attrition.
- Male attrition is higher than female attrition.
- Early-tenure employees have higher attrition rates.
